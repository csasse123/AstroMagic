PiMagic & AstroMagic Installation Guide

© 2025–2026 Christian Sasse & Craig Stocks | pimagicstudio.com

Overview

The PiMagic/AstroMagic workflow requires four components:

Current release: PiMagic Studio v2.4 (build v2.4-0005), paired with AstroMagic 2.4-0005. Always install AstroMagic and the PsMagic Actions that are bundled with this PiMagic build (see the install steps below) so the PixInsight script and the Photoshop plugin stay version-matched.

  1. PiMagic — PixInsight script for automated image processing pipeline (installed via repository)
  2. RC-Astro CLI — mandatory stand-alone rc-astro command-line tool used by PiMagic v2.4 for BlurXTerminator, NoiseXTerminator, and StarXTerminator. Download from RC-Astro Stand-Alone Tools.
  3. AstroMagic — Photoshop UXP plugin for layer organization and enhancement (installed from PiMagic’s Welcome Wizard, plugin checker, or Tools tab)
  4. PsMagic Actions — Photoshop action set used by AstroMagic (installed from PiMagic’s Welcome Wizard, plugin checker, or Tools tab; required for v2.1 and later, including the current AstroMagic 2.4-0005)

Quick Start (Expert Users)

  1. PiMagic → Resources → Updates → Manage Repositories → Add https://pixinsight.pimagicstudio.com/ → Check for Updates → Restart
  2. RC-Astro CLI → Download from RC-Astro Stand-Alone Tools → Install the macOS .pkg or Windows x64 .exe → activate BXT/NXT/SXT if prompted → run rc-astro download-models
  3. AstroMagic → PiMagic Welcome Wizard / Check Plugins / Tools tab → Install Plugin → Creative Cloud installs → Restart Photoshop
  4. PsMagic Actions → Open Photoshop → PiMagic Welcome Wizard / Check Plugins / Tools tab → Install Actions (runs automatically in Photoshop)

Detailed instructions for each component follow below.

Mosaics are now produced in a single PiMagic run. You no longer run PiMagic a second time and there is no “two-cycle” or “two-pass” mosaic step. In one run PiMagic stacks and processes every pane, plate-solves each pane, then aligns the panes by coordinates (PixInsight MosaicByCoordinates) onto one common full canvas and hands the already-aligned panes off to AstroMagic. AstroMagic / Photoshop then only blends the seams — it does not re-align the panes. Because PiMagic owns the coordinate alignment in the same run, the only setup that matters for mosaics is that plate solving works: make sure ASTAP and its star databases are installed (see below).

PiMagic Installation (PixInsight Script)

Prerequisites

  1. PixInsight 1.9.4 (Lockhart) or later installed (64-bit) — mandatory. PiMagic v2.4 uses the V8 JavaScript engine that ships in PixInsight 1.9.4; version 1.9.3 and earlier (SpiderMonkey engine) will not run it. Update PixInsight first if you are on an older version.
  2. Stand-alone RC-Astro CLI installed and licensed for the RC-Astro tools you use. PiMagic v2.4 calls rc-astro directly for BlurXTerminator, NoiseXTerminator, and StarXTerminator. Installing the PixInsight RC-Astro process modules alone is not sufficient.
  3. ASTAP plate solver installed with W08 and D50 star databases — see details below
  4. Gaia DR3 and Gaia DR3SP databases installed in PixInsight (required for SPCC) — see details below

Installation via Repository

PiMagic is installed through PixInsight’s built-in update system:

  1. In PixInsight, go to Resources → Updates → Manage Repositories
  2. Click Add
  3. Enter the repository URL: https://pixinsight.pimagicstudio.com/
  4. Click OK to close the Manage Repositories dialog
  5. Go to Resources → Updates → Check for Updates
  6. Click Apply to install the PiMagic package
  7. Quit PixInsight and confirm installation of updates when prompted
  8. Restart PixInsight

Accessing PiMagic

After installation, PiMagic will be available at:

Script → PiMagic Studio → PiMagic

PiMagic License Activation

On first launch, the license activation dialog will appear:

  1. Enter your license key from your purchase confirmation email
  2. Click Activate
  3. The dialog will confirm activation with your registered name

Managing Your License: Access the Tools tab to activate, deactivate, or view your PiMagic Studio license status. This one license covers PiMagic and AstroMagic. There is no separate AstroMagic license entry or activation step. Deactivating in PiMagic frees up an activation slot for use on another machine.

Mandatory: Install RC-Astro CLI for PiMagic v2.4

Required: PiMagic v2.4 does not run BlurXTerminator, NoiseXTerminator, or StarXTerminator through the PixInsight RC-Astro process modules. It requires the stand-alone rc-astro command-line tool. Without the CLI, the BXT/NXT/SXT stages cannot run.
  1. Download the stand-alone tools from RC-Astro Stand-Alone Tools.
  2. Install the macOS universal .pkg on Mac or the Windows x64 .exe on Windows.
  3. Use your RC-Astro account activation commands for BlurXTerminator, NoiseXTerminator, and StarXTerminator if the CLI reports that a product is not licensed. Existing RC-Astro product licenses are used; the CLI itself is free for license holders.
  4. Run rc-astro download-models once to pre-download the AI models.
  5. Launch PiMagic and run Tools → Check Plugins. Confirm that the RC-Astro CLI and the BXT/NXT/SXT license checks pass before starting a processing run.

Updating PiMagic

Future updates are delivered automatically through the repository:

  1. Go to Resources → Updates → Check for Updates
  2. Install any available updates
  3. Restart PixInsight

Troubleshooting

Script Not Appearing in Menu

  1. Ensure you quit and restarted PixInsight after applying updates
  2. Go to Resources → Updates → Check for Updates and verify installation completed
  3. Check Process Explorer (Ctrl+Alt+P on Windows, Cmd+Alt+P on Mac) → Scripts → All Scripts to verify installation

Optional: Installing GraXpert Process

For GraXpert integration in PixInsight, you can install Joël Vallier’s GraXpert Process. This requires the GraXpert desktop application to be installed first.

Part A: Install GraXpert Desktop Application

  1. Download GraXpert from graxpert.com
  2. Install GraXpert:
    • Windows: Run the downloaded .exe file
    • macOS: Open the .dmg file and drag GraXpert to your Applications folder
    • Linux: Make the file executable with chmod u+x ./GraXpert-linux
  3. Launch GraXpert and process one image in AI mode to download the AI models
Note: The first AI model download may take several minutes.

Part B: Install GraXpert Process in PixInsight

Prerequisites: PixInsight 1.9.4 (Lockhart) or later (the version PiMagic v2.4 requires); GraXpert version 3.0.0 or higher

  1. Go to Resources → Updates → Manage Repositories
  2. Click Add
  3. Enter: https://pixinsight.deepskyforge.com/update/graxpert-process/
  4. Important: Don’t forget the trailing slash “/” at the end!
  5. Click OK
  6. Go to Resources → Updates → Check for Updates
  7. Click Apply to install the GraXpert Process package
  8. Exit PixInsight and confirm the installation of updates
  9. Restart PixInsight

After installation, GraXpert Process is available under Process → <Etc> → GraXpert

Required: Installing ASTAP (Plate Solving)

ASTAP (Astrometric STAcking Program) is a free plate-solving application required by PiMagic for astrometric solutions. ASTAP must be installed along with star databases before running PiMagic. PiMagic uses different databases depending on the field of view: W08 for wide-field and nightscape images (FOV > 20°), and D50 for narrow-field deep-sky images (FOV < 10°). Both databases should be installed for full compatibility.

Windows Installation

  1. Download ASTAP from: hnsky.org/astap.htm
  2. Run the downloaded installer (.exe) and follow the installation wizard
  3. When prompted, select the default installation directory (or choose your preferred location)
  4. After ASTAP is installed, you must also install the star database (see below)

macOS Installation

  1. Download ASTAP for macOS from: hnsky.org/astap.htm
  2. Open the downloaded .dmg file
  3. Drag the ASTAP application to your Applications folder
  4. If macOS blocks the app, go to System Settings → Privacy & Security → click “Open Anyway”
  5. After ASTAP is installed, you must also install the star database (see below)

Installing ASTAP Star Databases (Required)

ASTAP requires star databases for plate solving. PiMagic automatically selects the appropriate database based on your image’s field of view. Install both databases for full compatibility:

W08 Database (wide-field, nightscape — FOV > 20°):

  1. Download the W08 database from: hnsky.org/astap.htm#star_databases
  2. Windows: Run the W08 database installer — it will automatically place files in the correct ASTAP directory
  3. macOS: Extract the downloaded archive and copy the database files to the ASTAP database folder (typically /Applications/astap/data/ or the folder shown in ASTAP’s settings)

D50 Database (narrow-field, deep-sky — FOV < 10°):

  1. Download the D50 database from: hnsky.org/astap.htm#star_databases
  2. Windows: Run the D50 database installer — it will automatically place files in the correct ASTAP directory
  3. macOS: Extract the downloaded archive and copy the database files to the ASTAP database folder

Note: For medium-field images (10–20°), ASTAP may also use the G05 database if installed.

Nightscape Mosaics: Two Alignment Methods

When you build a multi-pane nightscape / landscape mosaic, PiMagic offers two ways to align the panes. The control is the Mosaic: dropdown shown next to the Nightscape checkbox (it appears only when Nightscape is checked). Both methods run in a single PiMagic run — the choice only decides who aligns the panes, not how many PiMagic passes you make.

  1. Coordinates (default, recommended) — PiMagic plate-solves every pane and aligns them by coordinates using PixInsight MosaicByCoordinates (forced to a Stereographic projection for wide nightscape geometry), then hands the pre-aligned panes to AstroMagic, which only blends them. This is the same idea as the deep-sky mosaic and gives sub-pixel registration plus PiMagic-owned whole-mosaic annotation. Requires ASTAP and the wide-field W08 database so the panes solve. Use this whenever the panes contain enough real sky/stars to plate-solve reliably.
  2. Photoshop Align+Blend (the older v2.0 behaviour) — PiMagic skips coordinate alignment, saves the pane outputs, and AstroMagic / Photoshop runs its own feature-based Auto-Align and then Auto-Blend on all panes. Choose this for very wide / ultra-wide panoramas, large foregrounds, or sparse star fields where plate solving the individual panes is unreliable, so you let Photoshop stitch them. (Whole-mosaic coordinate annotation is not produced in this mode.)
Tip: Leave the dropdown on Coordinates unless your nightscape panes will not plate-solve. The Coordinates method depends on a working ASTAP installation; the Photoshop Align+Blend method does not need ASTAP for the alignment step but still relies on AstroMagic + the PsMagic Actions in Photoshop.

Verifying ASTAP Installation

  1. Launch ASTAP
  2. Open any astronomical FITS or TIFF image
  3. Click “Solve” to attempt a plate solve
  4. If the solve succeeds, ASTAP and the database are correctly installed
  5. If it fails with a database error, verify the database files are in ASTAP’s data directory

Required: Installing Gaia DR3 and DR3SP Databases (PixInsight)

PiMagic uses SPCC (Spectrophotometric Color Calibration) which requires the Gaia DR3 and Gaia DR3SP star databases installed in PixInsight. Without these databases, SPCC color calibration will fail.

Installation Steps

  1. In PixInsight, go to Resources → Updates → Manage Repositories
  2. Verify that the standard PixInsight repository is listed (it should be there by default)
  3. Go to Resources → Updates → Check for Updates
  4. In the update list, look for “Gaia DR3” and “Gaia DR3SP” database packages
  5. Select both packages and click Apply to install
  6. Quit PixInsight and confirm installation when prompted
  7. Restart PixInsight

Verifying Installation

To confirm the databases are properly installed:

  1. Open any image in PixInsight
  2. Go to Process → ColorCalibration → SpectrophotometricColorCalibration
  3. In the SPCC dialog, check that “Gaia DR3” and “Gaia DR3SP” catalogs appear in the catalog dropdown
  4. If the catalogs are missing, repeat the installation steps above
Note: The Gaia DR3 and DR3SP database downloads are large (several GB total). Ensure you have sufficient disk space and a stable internet connection during installation.

AstroMagic Installation (Photoshop Plugin)

Prerequisites

  1. Adobe Photoshop 2023 (v24.0) or later
  2. Adobe Creative Cloud Desktop app installed and running
  3. PiMagic installed in PixInsight (the AstroMagic plugin and actions are included with PiMagic)

Installation via PiMagic Welcome Wizard, Plugin Checker, or Tools Tab

AstroMagic and PsMagic Actions are installed from the same PiMagic controls in PixInsight. New users see them in the first-run Welcome Wizard; they are also available later from Tools → Check Plugins and from the Tools tab:

  1. Launch PiMagic in PixInsight (Script → PiMagic Studio → PiMagic)
  2. Use the first-run Welcome Wizard, Tools → Check Plugins, or the Tools tab
  3. In the AstroMagic section, click Install Plugin
  4. The Adobe Creative Cloud installer will launch automatically
  5. You will see a security warning: “This plugin hasn’t been verified by Adobe”
  6. Click Install locally
  7. You will see another warning about third-party plugins
  8. Click OK to confirm the installation
  9. Wait for the installation to complete
  10. Restart Photoshop

Accessing AstroMagic

After installation, access AstroMagic in Photoshop:

Plugins → AstroMagic

The AstroMagic panel will open and can be docked anywhere in your workspace.

Troubleshooting

Plugin Not Appearing in Plugins Menu

  1. Restart Photoshop completely (close and reopen)
  2. Verify the plugin is installed: Go to Plugins → Manage Plugins in Photoshop
  3. Look for AstroMagic in the list and make sure it is enabled
  4. Check that your Photoshop version is 2023 (v24.0) or later

Installation Fails with Error Code

  1. Make sure the .ccx file is on the same drive as Photoshop
  2. Use the Open Folder button in PiMagic’s Tools tab to verify the .ccx file exists
  3. Quit Creative Cloud Desktop completely, restart it, then try again

macOS Security Warning

If you see “can’t be opened because it is from an unidentified developer”:

  1. Go to System Preferences → Security & Privacy → General
  2. Click Open Anyway next to the blocked plugin message

Installing PsMagic Actions (Required)

AstroMagic v2.1 and later (the current release is AstroMagic 2.4-0005, paired with PiMagic v2.4-0005) requires the PsMagic Actions action set to be installed in Photoshop. These actions provide reliable Smart Filter and layer group functionality.

Installation via PiMagic Welcome Wizard, Plugin Checker, or Tools Tab

Important: Photoshop must be open before clicking Install Actions.
  1. Open Photoshop (it must be running)
  2. Launch PiMagic in PixInsight (Script → PiMagic Studio → PiMagic)
  3. Use the first-run Welcome Wizard, Tools → Check Plugins, or the Tools tab
  4. In the AstroMagic section, click Install Actions
  5. PiMagic connects directly to Photoshop and runs the installer automatically — no file browsing needed
  6. The installer removes any existing PsMagic Actions set and loads the current version
  7. A success confirmation will appear when installation is complete

Verify Installation

After installation, you should see PsMagic Actions listed in your Actions panel (Window → Actions). The action set contains actions used by AstroMagic for layer group creation, continuum subtraction, and structure enhancement. Note that there should be only one set of PsMagic Actions listed in the Actions panel.

AstroMagic License Status

AstroMagic uses the PiMagic Studio license activated in PiMagic. There is no separate AstroMagic license key, license tab, activation button, or deactivation button.

  1. Activate your PiMagic Studio license in PixInsight under PiMagic → Tools → Manage License
  2. Open AstroMagic in Photoshop
  3. Use Refresh PiMagic License in AstroMagic only if the displayed status has not updated yet

Managing Your License: All activation, deactivation, and transfer operations happen in PiMagic. AstroMagic follows the same license state.

License Information

Each PiMagic Studio license allows activation on a limited number of machines (see your purchase details). To transfer a license to a new machine:

  1. PiMagic: Go to Tools tab → Manage License → Deactivate
  2. AstroMagic: No separate action is required; it uses the PiMagic license state

After deactivation, you can activate on your new machine using the same PiMagic Studio license key.

Updating AstroMagic

To install the current bundled AstroMagic files after a PiMagic update:

  1. Update PiMagic via Resources → Updates → Check for Updates (the updated AstroMagic files are included with PiMagic updates)
  2. In PiMagic’s Welcome Wizard, plugin checker, or Tools tab, click Install Plugin to install the current bundled plugin
  3. If the bundled PsMagic Action set changed, click Install Actions (this automatically removes old versions)
  4. Restart Photoshop
Note: Do not uninstall the old version first – this may delete your preferences and settings.
